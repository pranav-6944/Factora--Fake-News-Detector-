Install in 3 Simple Steps

1

Download the Extension

Click the download button above to get factora-extension.zip. Then extract it to any folder on your computer using Windows Explorer or 7-Zip.

factora-extension.zip
Right-click the zip → "Extract All…"
2

Open Chrome Extensions

Open Chrome (or any Chromium browser like Edge or Brave) and navigate to the extensions page. Enable Developer mode using the toggle in the top-right corner.

chrome://extensions/

Enable "Developer mode" toggle
3

Load the Extension

Click "Load unpacked" and select the extracted browser_extension folder (the one containing manifest.json). FacTora will appear in your browser toolbar immediately.

Select: browser_extension/ folder

Look for the FacTora 🛡️ icon in your toolbar
Prerequisite: The FacTora app must be running locally on http://localhost:5000 for the extension to work. You're already on it — so you're all set! ✅
